Home Assistant

Control Center · Anna OS

Developer preview
Permissions and verification require an online Anna Agent.

This app saves non-secret permission drafts. Export the settings and paste the JSON into HA_POLICY_JSON on Anna's native Executa settings page. Verified actions use a short-lived approval queue. PIN and authenticator codes are entered in this interface, and passkeys work only when Anna's browser supports WebAuthn. All secrets are configured through Anna's native Executa settings.

Set up verification

Enter the initial PIN in Anna's native Executa credentials first. You'll use it to register a passkey; no PIN is stored in this App.

For an authenticator app, generate an initial Base32 seed locally, add it to your authenticator, and enter that seed into Anna's HA_TOTP_SECRET credential.


      
For phone alerts, enter HA_PHONE_NOTIFY_SERVICE in Executa credentials (e.g. mobile_app_pixel_10_pro). A push notification asks you to open the Control Center; tapping it never approves a command. A direct app link is optional via HA_APPROVAL_LINK.
