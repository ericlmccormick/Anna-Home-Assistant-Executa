Before you start

You need a running Home Assistant server and an Anna Agent that can reach it.

Cloud Agent: Your Home Assistant server must be reachable through a public HTTPS address with a trusted certificate. Private IP addresses, localhost and .local hostnames won't work from Anna's cloud.

Home Assistant is not included with this App. You must already run it and create your own access token. Learn about Home Assistant

Connect in three steps

  1. Choose your Agent. Open Anna Agents. Confirm your Cloud Agent is online, or select an online Linux x86-64 Local Agent. This menu explains the options; it does not switch Agents.
  2. Open secure connection settings. Open Anna’s Executa Hub. Select Learned, find Home Assistant Connector, and choose Credentials. You can also reach it from Advanced → Executa → Home Assistant Connector → Credentials.
  3. Add your server address and access token. In the credential form, enter your HTTPS Home Assistant base URL in HA_URL and your long-lived access token in HA_TOKEN. Save there, return here, and select Test connection.
How to find your Home Assistant access token

In Home Assistant, open your profile (lower-left sidebar), find Long-lived access tokens, select Create Token, and copy it directly into the native Anna Executa credential form. Do not paste tokens into chat.

Choose permissions (optional)

  1. Choose your access levels below and select Copy settings. Sensor reads are enabled by default. To list lights or check their status, use Other entity states. Lights controls actions such as turning them on or off.
  2. Return to the same credential form, paste the settings into Permissions policy (HA_POLICY_JSON), and click Save. Then select Check active settings here to confirm. Save choices keeps your edits in Control Center until you apply them in the credential form.
  3. If you choose Verify, configure an approval method under Set up verification below. Review and approve pending actions in Identity verification.

Enter your Home Assistant access token only in Anna’s Executa credential form.

Set up verification

To use a PIN, set a 6–12 digit PIN in the Connector’s Approval and enrollment PIN field in Anna. Use that PIN only in Control Center when reviewing a request.

For an authenticator app, generate an initial Base32 seed locally, add it to your authenticator, and enter that seed into Anna's HA_TOTP_SECRET credential.
